# Reference

- **[Language reference](/reference/language/)**: the rules of the language, one page per topic.
  These pages are the specification, SPECS.md, split up; when the guide and the reference disagree,
  the reference is right.
- **[API reference](/reference/api/)**: every public declaration of the standard library, written
  by `eye doc` from the `##` comments in its source.
- **[The eye command](/reference/cli)**: what each command does and the flags it takes.
- **[Design](/design/)**: the goals, every decision with its reason, and the open questions.
