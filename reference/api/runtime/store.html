Module runtime.store ​

The in-memory store: everything a running program keeps, as one immutable value. Each commit is a pure function from one store to the next, and the runtime holds the only reference to the current one.

eye
import runtime.store

Types ​

Row ​

eye
pub type Row = { state: String, version: Int, schema: Int, ended: Bool }

An entity's saved state, and how many transactions have changed it. An entity that ended keeps a row with ended true, whose state says how it ended, so that its identity stays ended.

pub type EventRecord = { name: String, data: String }

A published event: its name and its value as bytes.

Commit ​

eye
pub type Commit = {
  writes: List(Write),
  runs: List(RunWrite),
  events: List(EventRecord),
  meta: List(MetaWrite),
  dropEvents: Int,
}

What one transaction writes, all at once.

  • dropEvents: Int: How many of the oldest events to drop, which no run can still wait for.

MemoryStore ​

eye
pub opaque type MemoryStore = {
  rows: Map(String, Map(String, Row)),
  kinds: Map(String, List(String)),
  entities: List(String),
  runs: Map(Int, Map(Int, String)),
  events: List(EventRecord),
  meta: Map(String, String),
}

Everything the store holds. Entity keys keep the order they were first saved in, which listings follow; runs are listed by number, which is the order they started in.

Runs are kept in buckets of 64 by their number, and rows by entity type, so that a commit, which rewrites a run at every step, replaces one small map and not a map of every run. A store whose only reference the runtime holds would be updated in place anyway once compiled; the interpreter copies.

MemoryStore.empty ​

eye
pub fn empty() -> MemoryStore

A store that holds nothing.

MemoryStore.forget ​

eye
pub fn forget(self, ids: List(Int)) -> MemoryStore

The store without the records of the runs ids. A journal or a database that wraps this store keeps a run's record itself while the run waits or after it ends, and only a ready run's record here (SPECS.md §15).
