Built-in functions ​

Functions every module can call without importing anything. Collection functions take the collection first, so they read well after |>: players |> add(p). Any of them can also be called as a method: players.size().

Output and failure ​

print ​

eye
fn print(values: List(a)) uses {stdio}

Writes the values, shown as string interpolation shows them and separated by spaces, and a line break to standard output. It takes any number of values, written as separate arguments: print("took", d).

unreachable ​

eye
fn unreachable(why: String) -> a

Stops the program, or the job's run, as a fault: Failed(Unreachable(why)). It is for states the code has already ruled out, never for failures that can happen.

log.debug ​

eye
fn log.debug(values: List(a))

Logs a line at debug level. A job that resumes doesn't log again what it logged before its last step. It takes any number of values, written as separate arguments.

log.info ​

eye
fn log.info(values: List(a))

Logs a line at info level. It takes any number of values, written as separate arguments.

log.warn ​

eye
fn log.warn(values: List(a))

Logs a line at warning level. It takes any number of values, written as separate arguments.

log.error ​

eye
fn log.error(values: List(a))

Logs a line at error level. It takes any number of values, written as separate arguments.

Tests ​

expect ​

eye
fn expect(condition: Bool)

Fails the test if the condition is false. For a comparison it shows the value it got: expected w.phase == Asleep, but w.phase is Running.

advance ​

eye
fn advance(by: Duration)

Moves the test's clock forward. Each job run that wakes on the way runs, in the order of its wake time, before advance returns.

clock ​

eye
fn clock(at: Instant) -> Handler

Used as with clock(2026-10-10 12:00 in "Europe/Dublin"): sets the test's clock. Without it, a test's clock starts at 2026-01-01 00:00 UTC.

memory ​

eye
fn memory(limit: Size) -> Handler

Used as with memory(64 MiB): sets the memory the test's runner has, which @memory and reserve! are admitted against, for the rest of the test. Without it, a test's runner has 1 GiB.

approve ​

eye
fn approve(what: String, by: who = "the person asked")

In a test, approves the one request a job is waiting for in approval!(…) whose text contains what, and fails the test when none or several do. The answer comes from by, or without it from the person asked; an answer from anyone else is refused, and the run keeps waiting.

decline ​

eye
fn decline(what: String, by: who = "the person asked")

In a test, declines the one request a job is waiting for in approval!(…) whose text contains what, as approve approves it.

fakes ​

eye
fn fakes(modules: List(Module), from: String) -> Fakes

Used as with fakes(notify, from: "receipts/"): calls to the contract modules replay the exchanges recorded in receipts/notify.json, checked against the contract's types. It takes any number of contract modules, written as separate arguments. Named first, as let sent = fakes(notify, from: …) and with sent, it lists the calls it answered: sent.calls(notify.send), each a record of the call's arguments and its key.

Time ​

sleep ​

eye
fn sleep(for: Duration) uses {wait}

In a job, sleep!(20 min) is a durable step: the run waits without holding memory, and resumes when the time comes, even after a restart. Outside jobs, sleep blocks; in tests it advances the clock.

sleepUntil ​

eye
fn sleepUntil(at: Instant) uses {wait}

In a job, sleepUntil!(08:00 in dublin) waits, without holding memory, until that time comes. Outside jobs it blocks; in tests it advances the clock.

Configuration ​

secret ​

eye
fn secret(name: String) -> Secret(String) uses {secret}

The secret of that name: the environment variable of the name in upper case, with - and . as _ (notify-token is NOTIFY_TOKEN), or the file of that name in the directory $EYE_SECRETS. It can't be shown or saved. Reading one uses secret "name", and in a job is a step: secret!(…).

env.get ​

eye
fn env.get(name: String) -> Option(String) uses {env}

The environment variable of that name, if it is set: for configuration that isn't secret, such as a proxy's address.

Time ​

daily ​

eye
fn daily(at: Time, in: Zone, onGap: GapPolicy = Shift, onOverlap: OverlapPolicy = First) -> Schedule

Every day at that time on the zone's clock: @on(daily(07:40, in: dublin)). A job that takes a Date gets the firing's date in the zone. A time a daylight-saving change skips fires as far after the change as it was meant to be, unless onGap: Skip; a time it repeats fires the first time, unless onOverlap: Second or Both.

weekdays ​

eye
fn weekdays(at: Time, in: Zone, onGap: GapPolicy = Shift, onOverlap: OverlapPolicy = First) -> Schedule

Like daily, Monday to Friday.

cron ​

eye
fn cron(fields: String, in: Zone, onGap: GapPolicy = Shift, onOverlap: OverlapPolicy = First) -> Schedule

When the five fields of a crontab line say, on the zone's clock: @on(cron("*/20 7-9 * * mon-fri", in: dublin)). The fields are minute, hour, day of month, month (or jan to dec) and day of week (0 to 7, 0 and 7 being Sunday, or sun to sat), each *, a value, a range, a list or a step. When both day fields are given, a day matches if either does. Daylight-saving changes are handled as daily's are.

every ​

eye
fn every(interval: Duration) -> Schedule

At every multiple of the interval since midnight UTC: @on(every(15 min)) fires at :00, :15, :30 and :45.

now ​

eye
fn now() -> Instant uses {clock}

The current time: the test's clock in tests. In a job, now!() records it, so a resumed run sees the same time.

Concurrency ​

parallelMap ​

eye
fn parallelMap(c: Collection(a), f: fn(a) -> b, limit: Int = all) -> List(b)

Applies f to each element in tasks that run at once, at most limit of them, and returns the results in the elements' order. Tasks that wait, for the network or a timer, overlap. In a job, f may only compute.

both ​

eye
fn both(a: fn() -> x, b: fn() -> y) -> (x, y)

Runs a and b at once and returns both results when both have finished.

race ​

eye
fn race(fs: List(fn() -> a)) -> a

Runs the functions at once and returns the result of the first to finish; the others are cancelled at their next wait.

timeout ​

eye
fn timeout(after: Duration, f: fn() -> a) -> Option(a)

Runs f, and returns Some(result) if it finishes in time, or None, cancelling it at its next wait, if it doesn't.

taskGroup ​

eye
fn taskGroup(f: fn(TaskGroup) -> a) -> a

Runs f with a new task group, and returns f's result once every task the group spawned has finished. If a task fails, the others are cancelled at their next wait and the group fails with it; if every task left waits for a channel that no task will put into or close, the group fails.

channel ​

eye
fn channel(capacity: Int) -> (Sender(a), Receiver(a))

A channel that holds at most capacity values, as a Sender and a Receiver. A put waits while it is full, so a fast producer can't fill memory. Channels aren't durable: jobs talk through entities and events.

Waiting ​

poll ​

eye
fn poll(every: Duration, within: Duration, check: fn() -> Bool) -> Bool uses {wait}

In a job, poll!(every: 1 min, within: 6 h, fn { miniflux.ready!() }) calls check every interval until it returns true, and returns false if within runs out first. For a service that can't send an event when it is ready. Only the outcome is kept, so a long poll doesn't grow the run's history.

next ​

eye
fn next(event: Event(a), where: fn(a) -> Bool, within: Duration) -> Option(a) uses {wait, consume}

In a job, waits for the first event that matches, counting every one published since the run's previous step, so an answer that comes quickly isn't missed. None when within runs out.

reserve ​

eye
fn reserve(size: Size, f: fn() -> a) -> a uses {wait}

In a job, reserve!(256 MiB, fn { summarise!(items) }) waits until the runner can grant the memory, holds it while f runs, even across f's own waits, and gives it back when f returns, with f's result. Under pressure, runs of a higher @priority are granted memory first.

approval ​

eye
fn approval(what: String, from: who, within: Duration) -> Decision uses {wait}

In a job, asks a person to approve, and waits for the answer: Approved(approval), Declined or Expired. Only this can make an Approval.

lock ​

eye
fn lock(name: String, for: Duration, f: fn() -> a) -> a uses {wait}

In a job, lock!("ci", for: 30 min, fn { deploy!() }) waits until no other run holds the lock of that name, takes it for that long, runs f and gives the lock back when f returns, with f's result. The store keeps who holds a lock and until when. A run still waiting inside f when the time runs out ends as Failed(LockExpired(name)), and the next run takes the lock.

allDone ​

eye
fn allDone(runs: List(Run(a))) -> List(Outcome(a)) uses {wait}

In a job, allDone!([a, b]) waits until every run in the list has finished, and gives their outcomes in the list's order.

firstDone ​

eye
fn firstDone(runs: List(Run(a))) -> Outcome(a) uses {wait}

In a job, firstDone!([a, b]) waits until one of the runs has finished, and gives its outcome. It stops the others, which end as Failed(Killed).

Collections ​

size ​

eye
fn size(c: Collection(a)) -> Int

The number of elements.

isEmpty ​

eye
fn isEmpty(c: Collection(a)) -> Bool

Whether there are no elements.

add ​

eye
fn add(s: Set(a), x: a) -> Set(a)

The set with x in it; on a list, the list with x at the end.

remove ​

eye
fn remove(s: Set(a), x: a) -> Set(a)

The set without x; on a map, the map without the key x.

contains ​

eye
fn contains(c: Collection(a), x: a) -> Bool

Whether x is an element; for a map, a key; for a string, a substring.

insert ​

eye
fn insert(m: Map(k, v), key: k, value: v) -> Map(k, v)

The map with key set to value.

get ​

eye
fn get(m: Map(k, v), key: k) -> Option(v)

The value for key, or None; on a list, the element at an index. Same as m[key].

first ​

eye
fn first(c: Collection(a)) -> Option(a)

The first element, or None.

last ​

eye
fn last(c: Collection(a)) -> Option(a)

The last element, or None.

map ​

eye
fn map(c: Collection(a), f: fn(a) -> b) -> List(b)

Applies f to each element. On an Option or a Result, applies f to the value inside Some or Ok. On an Iter, gives an Iter that applies f as it is walked; f then only computes.

filter ​

eye
fn filter(c: Collection(a), keep: fn(a) -> Bool) -> List(a)

The elements for which keep is true; a set stays a set, and an Iter an Iter. Over Entity.all in a view, the runtime keeps the result up to date.

find ​

eye
fn find(c: Collection(a), test: fn(a) -> Bool) -> Option(a)

The first element for which test is true.

any ​

eye
fn any(c: Collection(a), test: fn(a) -> Bool) -> Bool

Whether test is true for some element.

all ​

eye
fn all(c: Collection(a), test: fn(a) -> Bool) -> Bool

Whether test is true for every element.

count ​

eye
fn count(c: Collection(a), test: fn(a) -> Bool) -> Int

How many elements test is true for; without test, the size.

reduce ​

eye
fn reduce(c: Collection(a), start: b, f: fn(b, a) -> b) -> b

Combines the elements, from start, left to right.

sum ​

eye
fn sum(c: Collection(a)) -> a

Adds the elements: numbers, durations or sizes.

average ​

eye
fn average(c: Collection(a)) -> Option(Float)

The mean of the numbers, an Int or a Float each, as a Float, or None when there are none: [1, 2].average() is Some(1.5). For an Int that rounds as / does, write xs.sum().div(xs.size()).

enumerate ​

eye
fn enumerate(c: Collection(a)) -> List((Int, a))

Pairs each element with its index, from 0; on an Iter, as it is walked.

drop ​

eye
fn drop(c: Collection(a), n: Int) -> List(a)

Everything after the first n elements; on an Iter, an Iter that skips them.

take ​

eye
fn take(c: Collection(a), n: Int) -> List(a)

The first n elements; on an Iter, an Iter that stops after them.

reverse ​

eye
fn reverse(c: Collection(a)) -> List(a)

The elements in reverse order.

sort ​

eye
fn sort(c: Collection(a)) -> List(a) where a: Ord

The elements in ascending order; equal elements keep their order.

keys ​

eye
fn keys(m: Map(k, v)) -> List(k)

The keys, in the order they were added.

values ​

eye
fn values(m: Map(k, v)) -> List(v)

The values, in the order their keys were added.

entries ​

eye
fn entries(m: Map(k, v)) -> List((k, v))

The key and value pairs.

toList ​

eye
fn toList(c: Collection(a)) -> List(a)

The elements as a list: what collects an Iter.

toSet ​

eye
fn toSet(c: Collection(a)) -> Set(a)

The elements as a set, without duplicates.

join ​

eye
fn join(c: Collection(a), separator: String) -> String

The shown elements, with separator between them.

flatMap ​

eye
fn flatMap(c: Collection(a), f: fn(a) -> Collection(b)) -> List(b)

Applies f to each element and joins the results; on an Iter, as it is walked.

zip ​

eye
fn zip(a: Collection(a), b: Collection(b)) -> List((a, b))

Pairs elements of a and b, as far as the shorter goes; an Iter when either is one.

iter ​

eye
fn iter(c: Collection(a)) -> Iter(a)

A lazy sequence of the elements, an Iter: xs.iter() |> map(f) |> take(3) applies f to three elements, whatever the size of xs. A map gives its (key, value) pairs, a string its characters.

Strings and numbers ​

lines ​

eye
fn lines(s: String) -> List(String)

The lines of s, without their line breaks: a line ends at \n or \r\n, and a line break at the end adds no empty line, so "a\r\nb\n".lines() is ["a", "b"] and "".lines() is [].

split ​

eye
fn split(s: String, separator: String) -> List(String)

The parts of s between separators.

trim ​

eye
fn trim(s: String) -> String

s without whitespace at either end.

lower ​

eye
fn lower(s: String) -> String

s with its letters in lower case.

startsWith ​

eye
fn startsWith(s: String, prefix: String) -> Bool

Whether s starts with prefix.

upper ​

eye
fn upper(s: String) -> String

s with its letters in upper case.

endsWith ​

eye
fn endsWith(s: String, suffix: String) -> Bool

Whether s ends with suffix.

replace ​

eye
fn replace(s: String, old: String, new: String) -> String

s with every occurrence of old replaced by new, from left to right: "a-b-c".replace("-", "+") is "a+b+c".

words ​

eye
fn words(s: String) -> List(String)

The words of s: the parts between runs of whitespace, with none empty. " a b\n" has the words ["a", "b"].

chars ​

eye
fn chars(s: String) -> Iter(Char)

The characters of s, in order, as an Iter: for c in s.chars() { … }.

bytes ​

eye
fn bytes(s: String) -> Bytes

The bytes of s in UTF-8, for scanning text byte by byte: src[i] == Some('"').

toText ​

eye
fn toText(b: Bytes) -> Option(String)

The text the bytes spell in UTF-8, or None if they aren't UTF-8.

toBytes ​

eye
fn toBytes(xs: List(Byte)) -> Bytes

The bytes of a list, in order, as Bytes: for bytes that aren't text, built or changed one at a time. toBytes([0xC3, 0xA9]).toText() is Some("é").

indexOf ​

eye
fn indexOf(s: String, part: String, from: Offset = start) -> Option(Offset)

Where the first part at or after from starts, or None if there is none. Without from, it looks from the start.

slice ​

eye
fn slice(s: String, range: Range(Offset)) -> Option(String)

The part of s between two positions: s.slice(s.start()..i). A range past either end is cut to fit; it is None when an end would split a character, as an Offset from another string may.

start ​

eye
fn start(s: String) -> Offset

The position before the first character of s.

end ​

eye

The position after the last character of s: s.slice(i..s.end()) is the rest of s from i.

after ​

eye
fn after(s: String, at: Offset, by: Int = 1) -> Option(Offset)

The position by characters after at, or None past the end: s.after(i) steps over the character at i.

before ​

eye
fn before(s: String, at: Offset, by: Int = 1) -> Option(Offset)

The position by characters before at, or None before the start.

charAt ​

eye
fn charAt(s: String, at: Offset) -> Option(Char)

The character that starts at at, or None at the end or inside a character.

code ​

eye

The character's Unicode code point: 'A'.code() is 65.

fromCode ​

eye
fn fromCode(n: Int) -> Option(Char)

The character with that Unicode code point, or None if there is none.

toJson ​

v as JSON, in the shape its type's schema describes (SPECS.md §17). A NaN or an infinity, which JSON has no number for, is a fault.

isOk ​

eye

Whether r is Ok.

eye

Whether r is Err.

mapErr ​

r with f applied to its error: parse(s).mapErr(BadNumber)? wraps the error in the caller's variant.

context ​

eye
fn context(r: Result(a, e), what: String) -> Result(a, Problem) where e: Show

r with its error turned into a Problem that says what was being done: fs.readText(path).context("reading {path}")?. On a Problem, it adds the line before the others.

parseInt ​

eye
fn parseInt(s: String, base: Int = 10) -> Result(Int, String)

Reads a whole number written in decimal, or in another base from 2 to 36: parseInt("ff", base: 16) is 255. Spaces around it are ignored; the error says what was wrong.

parseFloat ​

eye
fn parseFloat(s: String) -> Result(Float, String)

Reads a number written in decimal, with an optional fraction and exponent: "1.5", "-2", "6.02e23". Spaces around it are ignored; the error says what was wrong.

round ​

eye
fn round(x: Float) -> Float

The whole number nearest to x, as a Float, with halves away from zero: round(2.5) is 3.0. toInt makes it an Int.

floor ​

eye
fn floor(x: Float) -> Float

The largest whole number that isn't more than x, as a Float.

ceil ​

eye
fn ceil(x: Float) -> Float

The smallest whole number that isn't less than x, as a Float.

toInt ​

eye
fn toInt(x: Float) -> Option(Int)

The whole part of x, without its fraction, as an Int: x.round().toInt(). An infinity or NaN is None. On a fixed-width integer, x.toInt() is its value as an Int, which always fits, so it isn't an Option.

toFloat ​

eye
fn toFloat(n: Int) -> Float

The number n as a Float: the nearest one when n is too large to hold exactly.

nonzero ​

eye

Some(n) unless n is 0: what / and % take as a divisor.

div ​

eye
fn div(a: Int, b: Int) -> Option(Int)

Some(a / b), or None when b is 0, for a divisor that may be 0 without a match on nonzero: total.div(count) ?? 0. It rounds down, as / does: div(-7, 2) is Some(-4).

rem ​

eye

Some(a % b), or None when b is 0. The remainder has the sign of b, as with %: rem(-7, 2) is Some(1).

min ​

The smaller of a and b.

max ​

eye
fn max(a: t, b: t) -> t where t: Ord

The larger of a and b.

abs ​

n without its sign.

Fixed-width integers ​

wrappingAdd ​

eye
fn wrappingAdd(a: n, b: n) -> n

a + b wrapped into their type, modulo 2 to the power of its bits: for Bytes, 255 plus 1 is 0. a and b have the same fixed-width type: Byte, Int32, Int64, UInt32 or UInt64.

wrappingSub ​

eye
fn wrappingSub(a: n, b: n) -> n

a - b wrapped into their type, modulo 2 to the power of its bits: for Bytes, 0 minus 1 is 255.

wrappingMul ​

eye
fn wrappingMul(a: n, b: n) -> n

a * b wrapped into their type, modulo 2 to the power of its bits, as hashes multiply.

checkedAdd ​

eye

Some(a + b), or None when the sum doesn't fit their type.

checkedSub ​

eye
fn checkedSub(a: n, b: n) -> Option(n)

Some(a - b), or None when the difference doesn't fit their type: for Bytes, 0 minus 1.

checkedMul ​

eye
fn checkedMul(a: n, b: n) -> Option(n)

Some(a * b), or None when the product doesn't fit their type.

and ​

eye

The bits set in both a and b.

eye
fn or(a: n, b: n) -> n

The bits set in a, in b, or in both.

xor ​

eye
fn xor(a: n, b: n) -> n

The bits set in a or in b but not in both.

not ​

eye
fn not(a: n) -> n

Every bit of a flipped: for a signed type, -a - 1.

shiftLeft ​

eye
fn shiftLeft(a: n, by: Int) -> n

The bits of a moved up by by; bits moved past the top are lost, so by of the type's width or more gives 0. A negative by is a fault.

shiftRight ​

eye
fn shiftRight(a: n, by: Int) -> n

The bits of a moved down by by, keeping the sign of a signed type: Int32 -8 shifted by 1 is -4. A negative by is a fault.

Some(n) as a Byte when n is from 0 to 255, otherwise None: Byte.from(n) ?? 0.

Int32.from ​

Some(n) as an Int32 when n is from -2147483648 to 2147483647, otherwise None.

Int64.from ​

eye

Some(n) as an Int64 when it fits in 64 bits with a sign, otherwise None.

UInt32.from ​

eye

Some(n) as a UInt32 when n is from 0 to 4294967295, otherwise None.

UInt64.from ​
