Built-in types ​

Types every module can name without importing anything. Their values and operations are built into the language; the functions that work on them are the built-in functions.

Int ​

eye
type Int

A whole number of any size: arithmetic never overflows.

NonZero ​

eye
type NonZero(a)

A number that isn't 0: what / and % take as a divisor, so dividing can't fail. nonzero(n) makes one.

Float ​

eye
type Float

A 64-bit floating-point number.

Bool ​

eye
type Bool

true or false.

Char ​

eye
type Char

One Unicode character: 'a', '\n'.

String ​

eye
type String

Text, in UTF-8. Strings interpolate with {…}: "{name} has {n} items".

Byte ​

eye
type Byte

A whole number from 0 to 255, for binary formats; arithmetic on it is explicit: b.wrappingAdd(1). An ASCII character literal is a Byte where one is expected: '-'.

Bytes ​

eye
type Bytes

A sequence of bytes, for binary data, hashing and foreign functions.

Int32 ​

eye
type Int32

A 32-bit whole number, for binary formats and foreign functions; arithmetic on it is explicit: a.wrappingAdd(b), a.checkedAdd(b).

Int64 ​

eye
type Int64

A 64-bit whole number, for binary formats and foreign functions; arithmetic on it is explicit.

UInt32 ​

eye
type UInt32

A 32-bit whole number without a sign, for binary formats and foreign functions.

UInt64 ​

eye
type UInt64

A 64-bit whole number without a sign, for binary formats and foreign functions.

Instant ​

eye
type Instant

A moment in time, the same everywhere: 2026-10-10 07:40 in dublin.

Date ​

eye
type Date

A day of the calendar, without a time or a zone: 2026-10-10.

Time ​

eye
type Time

A time of day, without a date or a zone: 07:40. A range of times may wrap midnight: 23:00..08:00.

Duration ​

eye
type Duration

A length of time: 20 min, 3 days.

Zone ​

eye
type Zone

A time zone, by its IANA name: "Europe/Dublin".

Schedule ​

eye
type Schedule

When a job runs by the clock: daily(07:40, in: dublin), every(15 min).

Size ​

eye
type Size

An amount of memory: 64 MiB.

List ​

eye
type List(a)

A growable array. Like every collection it is a value: passing one never shares later changes.

Map ​

eye
type Map(k, v)

Keys and their values, in the order the keys were added.

Set ​

eye
type Set(a)

Values without duplicates.

Iter ​

eye
type Iter(a)

A lazy sequence: xs.iter() gives one, and map, filter, take, drop, enumerate, zip and flatMap on it give another without building lists in between. Each walk computes it again from its source; toList collects it. It can't be saved, compared or printed.

Range ​

eye
type Range(a)

The values from start up to end: 0..n leaves end out and 0..=n includes it.

Ref ​

eye
type Ref(e)

A reference to an entity: an identity, not a pointer, so it can be stored, sent and saved, and a Ref(World) can't be confused with a Ref(Player).

Run ​

eye
type Run(a)

A started run of a job. In a job, run.join!() waits for its Outcome; a test or main reads it with run.outcome(), an Option(Outcome(a)) that is None while the run is still going.

Key ​

eye
type Key

An idempotency key: a command sent again with the same key happens once.

Secret ​

eye
type Secret(a)

A value that can't be printed or saved, such as a token: secret("notify-token").

Approval ​

eye
type Approval

A person's approval, which only approval!(…) gives: ending an entity, or a @destructive command or function, needs one. ok.what is the text that was approved and ok.by who approved it, the from: of approval! as text, for audit logs.

Version ​

eye
type Version

The version of something another service keeps, which a @fresh command checks is still current.

Event ​

eye
type Event(a)

Something a contract's service publishes: jobs wait for one with next!(…) or start on one with @on(event(…)).

TaskGroup ​

eye
type TaskGroup

A running task group, as taskGroup(fn group { … }) gives it: group.spawn(fn { … }) starts another task, which the group waits for. It can't be saved, so it can't be live across a !.

Sender ​

eye
type Sender(a)

The end of a channel that puts: send.put(x) waits while the channel is full, and send.close() ends it, after which a put fails. It can't be saved.

Receiver ​

eye
type Receiver(a)

The end of a channel that takes: for x in receive { … } reads until the channel is closed and empty, and receive.take() gives the next value, or None once it is closed and empty. It can't be saved.

Collection ​

eye
type Collection(a)

What the collection functions take: any of List, Set, Map, Range, Iter, Bytes, Option, and String where it makes sense. It stands for those here; programs write the collection's own type.

Handler ​

eye
type Handler

What with applies in a test, such as clock(…).

Fakes ​

eye
type Fakes

What fakes(…) gives: with applies it, as a Handler, and calls lists the calls it answered.

Module ​

eye
type Module

A module named as a value, as fakes(notify, from: …) takes it.

Trigger ​

eye
type Trigger

What starts a job in @on(…): a schedule, enters(view), leaves(view) or event(…).

View ​

eye
type View

A view named as a value, as enters(view) takes it.
